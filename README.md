# QuantumLab Studio v0.1

## Run locally
Install Python 3.10+, then run in this folder:
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Hugging Face Spaces
Create a **new Space using the Docker SDK** and upload these four files. A Static HTML Space cannot directly run this Streamlit server.

## Current implementation
The Mach–Zehnder interferometer is a simplified ideal two-path single-photon model. Other menu items are placeholders for later development; this is not yet a complete library of quantum experiments.
